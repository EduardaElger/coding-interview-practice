# Coding Interview Practice

Repositório dedicado à prática de algoritmos, estruturas de dados e resolução de problemas de programação utilizando Go.

O objetivo é desenvolver **raciocínio algorítmico**, melhorar a capacidade de identificar padrões e praticar a escrita de soluções eficientes e legíveis.

## 📚 Conteúdos

* Arrays
* Hash Maps / Hash Sets
* Strings
* Two Pointers
* Sliding Window
* Stack e Queue
* Binary Search
* Linked Lists
* Trees
* Heaps / Priority Queues
* Graphs
* Recursion
* Backtracking
* Dynamic Programming

## 🎯 Prática

Para cada problema, o objetivo é:

1. Entender o problema e suas restrições;
2. Identificar uma solução inicial;
3. Buscar uma solução mais eficiente quando possível;
4. Implementar a solução em Go;
5. Analisar complexidade de tempo e espaço;
6. Considerar casos extremos;
7. Escrever testes quando aplicável.
